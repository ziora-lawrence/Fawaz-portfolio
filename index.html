About

Clean code, clear communication, sites that load quickly.

I am a full-stack web developer. I build marketing sites, online stores and custom web applications with a strict focus on speed, accessibility and search visibility, because a site that is slow or hard to use costs its owner money every day.

Every project starts with a short conversation about your goals and your customers. From there I plan the structure, design the pages, write the code by hand and test across devices before anything goes live. You receive the full source code and a short handover guide when the work is done.

Standards

Every site is built to a performance budget.

These are Google's thresholds for a good page experience. I test each project against them on a mid-range phone over a throttled connection before launch.

LCP
≤ 2.5 s

Largest Contentful Paint

The main content is visible quickly.

INP
≤ 200 ms

Interaction to Next Paint

Taps and clicks respond without lag.

CLS
≤ 0.1

Cumulative Layout Shift

Nothing jumps around while loading.

  • Lighthouse score of 90 or higher
  • WCAG 2.2 AA accessibility
  • HTTPS and security headers
  • Responsive from 320 px upward
  • Semantic HTML and clean metadata
  • Tested in Chrome, Safari and Firefox

FAQ

Common questions.

How long does a website take?

A five-page site usually takes about two weeks once I have your text and images. Larger sites and applications take three to eight weeks depending on scope.

What do I need to provide?

Your logo, brand colours if you have them, the text for each page and any photos. If you need help with copy or imagery, we can plan that during discovery.

Do you handle the domain and hosting?

Yes. I can register the domain, set up fast hosting and configure email, all under accounts that belong to you.

Will I own the code?

You own the finished website and its source code once final payment is made.

What happens after launch?

Every project includes thirty days of free bug fixes. After that you can manage the site yourself or choose a monthly care plan.
